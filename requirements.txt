# 第 70 条：原文件全是无上限的 `>=`，全新环境装出来是「ABI 轮盘赌」——
# 典型如 numpy>=1.24 允许 2.x 配 opencv-python>=4.8.1，而 4.10 之前的 opencv wheel
# 与 numpy 2.x 不兼容，冻结/源码运行都可能崩在 import。这里给每个依赖补上下限+上限，
# 下限锚定到与实测兼容的版本、上限挡住下一个大版本（破坏性变更通常发生在大版本）。
# 注释里的「实测」= 本项目实际跑通 H.264/NVENC 的 fps-screen 环境版本（2026-09-03）。
mss>=9.0.1,<11              # 实测 10.2.0
opencv-python>=4.10,<6      # 实测 5.0.0.93；>=4.10 是首个提供 numpy2 兼容 wheel 的系列
numpy>=1.26,<3              # 实测 2.2.6；与 opencv>=4.10 配对安全
pillow>=10.0.0,<13          # 实测 12.3.0
pywin32>=306,<400           # 实测 312
# H.264 视频编码（host.codec.encoder!="jpeg"）：NVENC 硬件/x264 软件，带宽比 JPEG 降 5-20 倍
av>=12.0.0,<18              # 实测 17.1.0
