# 常见问题（FAQ）

> 自 README 下沉（实现方案 §11.3 / E3）。深度排障（需要看日志、改配置、装 vendor 的）
> 见 [`install.md`](install.md) §6；本文只收「现象 → 一步处理」。

| 现象 | 处理 |
|---|---|
| 局域网里连不上共享端 | 默认只监听 `127.0.0.1`：控制台「传输参数」把监听地址改成 `0.0.0.0` 并**重启共享端** |
| 观看端一直「连接中/无画面」 | 先用局域网直连验证：观看端填 `共享端IP:5700`，`ping` 确认可达 |
| 局域网能连、公网连不上 | ①确认隧道已启动，隧道本地端口 = 共享端 `host.port`（默认 5700）且类型为 TCP；②旧版曾要求「共享端同时监听 IPv6 回环」，v1.4.0 起默认回环双栈已解决；若日志出现「已配置 frp 隧道，但本机只监听了 …（未覆盖 IPv6 回环）」（IPv6 被系统禁用等），把隧道本地地址显式改成 `127.0.0.1`，或把监听地址设为 `0.0.0.0` 后重启。判别方法：共享端启动后会自动做一次公网回连自检，成功记「公网隧道自检通过」，失败会写明原因 |
| **共享端开了登录，观看端却看不到登录框** | 登录框**只在 TCP 握手成功之后**才会弹，按顺序查两处：①**共享端是否在运行**——进程没起来（或窗口被关掉）时隧道日志会刷 `连接映射目标 … 失败, 连接被拒绝`，观看端停在 `连接提前关闭，收到的数据不完整`，此时**永远不会**弹登录框；②观看端日志里搜 `登录框`：`需要账户（服务端要求登录），已弹出登录框` = 确实弹了，`登录框处于冷却中（N 秒后可再次弹出）` = 上一次是手动点了取消。旧版本在输错凭据后会静默压住登录框 30 秒以上（叠加退避），v1.4.0 起改为**约 1 秒后带原因重弹** |
| 连上但要求登录 / 输错一次后登录框"消失" | 默认开启账户准入；输错凭据时登录框会红字显示服务端原因（`账号不存在`/`用户名或密码错误`）并预填上次用户名，约 1 秒后自动重弹，直接改对再点「登录」即可。「账户注册」为 `仅首个账户`/`关闭` 时注册会被拒绝，原因同样显示在框内 |
| 忘记共享端口令 / 想换账号 | 共享端控制台「传输参数」→「账户注册」改为 `开放`（或 `仅首个账户`），然后在观看端登录框点「注册并登录」新建账号；也可清掉 `%LOCALAPPDATA%\TeamVision\accounts.json` 后用同样方式重建（会清空所有已有账号） |
| 连上但黑屏 | 独占全屏采集黑屏：把 `capture.backend` 设为 `dxgi`，或改为窗口化/无边框全屏（源码运行也有效，见 README「从源码构建」） |
| 画面卡顿、延迟高 | 降 `fps`/`scale`/`bitrate_kbps`，开启 `perf.adaptive`，或用 `capture.region` 限定区域。延迟读数看悬浮窗状态行（P95 后缀为 30 秒窗口的 95 分位，跨机时钟差会引入偏差，以相对趋势为主） |
| 双击 exe 无反应 | 查看 `%LOCALAPPDATA%\TeamVision\logs\` 当日日志；确认 `_internal` 目录与 exe 同级未被删改 |
| 提示「未找到 frpc 程序」 | 把 `frpc.exe` 放到 `fps-host\`、`fps-viewer\` 的上一级目录（安装包会自带一份） |
| 被杀毒/反作弊误报 | 本工具不读写游戏内存、不注入、不挂全局钩子；发布版已关 UPX 并 onedir 化（去掉"解压到临时目录执行"的经典误报链）。仍被报时优先添加白名单，并注意：竞技游戏中把画面共享给队友属于不公平优势，风险自担（见 README 免责声明） |
