## 1. 改动清单

### 1.1 打包：onefile → onedir（最高优先级）

| 文件 | 改动 |
|---|---|
| `fps-host.spec`、`fps-viewer.spec` | `EXE(...)` 改为 `exclude_binaries=True`，新增 `COLLECT(...)`；仍禁止 UPX |
| `build_exe.bat` | 签名与收尾提示改指 `dist\fps-host\fps-host.exe`、`dist\fps-viewer\fps-viewer.exe`；frpc 复制到 `dist\` 根 |
| `installer.iss` | `[Files]` 整目录安装到 `{app}\fps-host`、`{app}\fps-viewer`；快捷方式、`[Run]`、`UninstallDisplayIcon` 同步 |
| `build_installer.bat` | 前置存在性检查改指 onedir 路径 |
| `sign_exe.ps1` | `-Files` 默认值改为 onedir 路径 |

**为什么**：onefile 启动时把自己解压到 `%TEMP%\_MEIxxxxxx` 再从临时目录执行子进程，"写入临时目录 → 执行"是
杀软/EDR 的经典启发式链，也是 README 自己记录的误报来源；顺带把冷启动从"解压 ~100MB"变成直接加载。

**副作用（已在代码里处理）**：onedir 下 exe 位于 `<安装根>\fps-host\`，两个程序不再共享同一个 exe 目录。

- `common.data_dir()`：冻结运行时改为**优先 `%LOCALAPPDATA%\TeamVision`**（两端共享 config.json / accounts.json，
  且安装包升级覆盖程序目录时不会连配置一起删）。源码运行仍优先项目目录。
- `common._migrate_from_exe_dir()`：冻结运行时把**安装根**也作为旧配置位置，onefile 时代写在 `{app}\config.json`
  的设置能迁移过来，不会"升级后等于重置"。
- 新增 `common.app_dirs()`：把"exe 目录 + 上一级安装根"作为搜索路径。host/viewer 找 `frpc.exe` 都用它，
  所以 `frpc.exe` 放在安装根即可被两端找到。

### 1.2 默认安全值 + 一次性迁移

| 文件 | 改动 |
|---|---|
| `common.py` | `DEFAULT_CONFIG`：`listen_host` `0.0.0.0` → `127.0.0.1`；`auth.enabled` `false` → `true`；新增 `auth.allow_register`（默认 `open`）与顶层 `config_version`（= 2） |
| `common.py` | 新增 `CONFIG_VERSION`、`_upgrade_config()`、`_persist_upgrade()`，在 `load_config()` 中执行一次 |
| `common.py` | 新增 `register_policy()`（策略归一，host 与控制台共用同一语义） |
| `host_ui.py` | 「传输参数」新增**监听地址**输入框与**账户注册**下拉框（开放 / 仅首个账户 / 关闭），并即时落盘 |
| `host.py` | 新增 `_log_security_notice()`：监听全网卡 + 准入关闭、或准入开启但允许自助注册时写 WARNING |

**为什么**：默认形态下不再有对外监听的端口，也不存在"任何人连上就能看屏"的组合；
同时把"公网隧道已暴露、账户表还是空的"这种最危险的状态变成可控（`bootstrap`/`closed` 策略）。

**迁移只发生一次**，且只在用户**显式**写了旧默认值时才改：

- `listen_host` 为 `0.0.0.0`/`""`/`"::"` → 改为 `127.0.0.1`；
- `auth.enabled` 为 false → 改为 true；
- 自定义地址（如 `192.168.1.5`）、`fps`、`capture.*`、`codec.*`、频道列表等原样保留；
- 改动逐条写进日志，并提示"要恢复旧行为在控制台改回去"。

## 3. 用户可见的行为变更（升级前必读）

1. **默认只监听本机**：新装/迁移后，局域网内其他机器连不上，必须到控制台把监听地址改成 `0.0.0.0`
   并**重启共享端**（监听 socket 只在启动时绑定一次，状态栏会提示）。
2. **默认需要登录**：观看端首次连接要注册/登录；共享端能看到"谁在看"。注册策略默认仍是 `开放`
   （不改变既有体验），公网场景建议改为 `仅首个账户` 或 `关闭`。
3. **本仓库的 `config.json`**（工作目录里的开发配置）下次启动会被迁移：`0.0.0.0` → `127.0.0.1`、
   准入 → 开启。要保留旧的局域网直连行为，启动后在控制台改回去即可（日志里有迁移说明）。
4. **产物形态变了**：不能再只拷贝一个 exe，必须整个 `fps-host\` / `fps-viewer\` 目录一起分发。
5. **配置位置变了**：冻结运行时统一到 `%LOCALAPPDATA%\TeamVision\`（两个程序共享、升级不丢配置）。
